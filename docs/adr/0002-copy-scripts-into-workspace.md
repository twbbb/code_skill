# ADR 0002：标准脚本复制进测试工作区，而不是引用技能目录

- 日期：2026-10-24
- 状态：Accepted

执行用例用的通用脚本（`run_case.py`、`evidence.py`、Go 辅助等）可以放在技能目录里让测试工作区引用，也可以复制进每个测试工作区。

**决定：生成测试工作区时把标准脚本复制进 `testcase/`，和用例一起提交进被测服务的仓库。`svc-local-test` 每次开跑前比对副本和技能里的标准脚本，不一致就提示，由用户决定要不要同步。**

用例的价值在于可以复核：别人 clone 下被测服务的仓库，不装这个插件，`./run` 也要能复现。引用技能目录的话，工作区就依赖本机 `code_skill` 的路径和版本，换一台机器或者插件升级以后，旧的证据就复现不了。

## Consequences

- 各服务的副本会和标准脚本逐渐不一致。比对是唯一的防线，不能跳过。
- 修脚本的 bug 要改标准脚本，再同步到各个工作区。在副本里改的地方，下次同步时会被覆盖，除非把它提回标准脚本。
